This demo runs the actual DSP from the Contourtonist plugin — the ISO 226:2003 equal-loudness model, the rate-limited loudness controller, and the 16-biquad zero-added-latency filter bank — compiled unmodified to WebAssembly and running in an AudioWorklet.

What you’re hearing: as reproduction level falls, hearing loses bass (and some extreme treble) sensitivity faster than midrange. Pull the fader down with compensation on and the tonal balance survives; toggle it off to hear what a plain volume drop does. The curve pivots at 1 kHz where its gain is identically zero — it can change tonal balance, never level. In the real plugin the room level comes from a measurement microphone over the network; here the fader stands in for it, so there is no acoustic feedback loop to demonstrate. Uploaded audio never leaves your browser. The “safety clip” output stage is web-only.

Parts of this project were built with AI assistance; the DSP core is verified against a native build of the plugin’s own sources. © Stoatworks. Audio sources are synthesized in-browser — no third-party media.
